## One thing the brief assumed that is not true
Every generation's best genome (0 to 14) **reaches the flag** in its logged noop 0 sigma 0 run (`E1_E1_gen<NN>_best.json`: flag, x 3161, in 1947-2257 frames; scores 900-2700). Even generation 0's best already flags (it is the 11/12 training genome). So there are no "early generations dying at the x ~1220 hum spot" to show: the only run that dies there is the **start genome** (arm C, dies at x 1220). The montage therefore starts with the start genome and then shows each even generation passing the same level; what differs from generation to generation is small (score, "?" blocks, the mushroom), not flag vs death.
