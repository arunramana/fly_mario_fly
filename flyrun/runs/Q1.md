# Q1: the "?" block hums -> hearing neurons -> Giant Fiber -> jump (enemies removed; base f62583c)

**Result: the primary target works. The block at x 256 is hit in ONE jump (take-off 18 px before its left edge, the middle of the measured window), coin out. The mushroom block (336) is missed (two jumps, no hit); block 368 is hit by the second jump. With HUM off there are no hits. The shuffled brains do not reproduce it.** HUM_GAIN was chosen once and not touched afterwards.

## 0-1. Spec and brain
- `flyrun/SPEC.md`, section "Q: ?-blocks and mushroom" (Q1 Hum), as given plus the implementation notes (eye point = top-front corner of MARIO_BOX, "ahead of or above" = not fully behind his left edge).
- Brain `tutorials/_cache/W_steer_jo.npy` + `steer_jo_bodies.parquet` (`python -m flyrun.q1_brain`): W_steer + exactly the 20 JO neurons (13 JO-B1_a, 6 JO-B1_c, 1 JO-CA1), 656 neurons; the default W_steer.npy is untouched (`load_brain` reads FLYRUN_WFILE / FLYRUN_BODIES; the new `JO` mask exists only for this brain). 5 shuffled versions of the same 656-neuron count matrix with the Part 6b rule (degree + sign preserving, row-renormalised, seeds 0-4; the JO rows / columns are shuffled together with everything else): `W_steer_jo_shuf{0..4}_rn.npy`.
- **Check, HUM off, S3e smoke (enemies ON, noop 0, sigma 0): identical in every frame in x, A, Right and Left** (flag, 1947 frames, same presses). The TTMn trace is not bit-identical: the extra JO inputs renormalise the GF row, so TTMn differs by up to 0.0022 (about 2 % of the threshold) without changing a single button.

## 2. Hit window and HUM_GAIN (measurement; `runs/Q1_window.csv`, `Q1_hum_curve.csv`, `python -m flyrun.q1_calibrate`)
- **Window**: scripted, no fly, small Mario walking at the fly's walking speed (Right only), take-off at every position from -60 to +32 px from the block's left edge, Right+A held until the head bump: **one-jump hits for take-off offsets -27 ... -11** (ten take-off positions, x 229..245; 17 px wide; the walker advances 1-2 px per frame). Earlier take-offs (<= -28) peak below the block, later ones (>= -9) rise while he moves out from under it. **Middle: -19 px (x 237).**
- **Hum -> TTMn curve** (the brain driven by HOME_R + the hum while he walks in, no A): at x 238 the block's angular size is 0.4503 rad; TTMn(HUM_GAIN 1) = 0.007252; with the hum muted TTMn(0) = 0.000399 (same walk; the network is linear in this range, so TTMn(g) = TTMn(0) + g (TTMn(1) - TTMn(0))).
- **Calculation**: HUM_GAIN = (TTMN_THRESH 0.10 - 0.000399) / (0.007252 - 0.000399) = **14.5342**. Check at that gain: TTMn first reaches 0.10 at x 238 (offset -18); target -19 (the walk skips x 237). **Frozen: `Knobs.HUM_GAIN = 14.5342`.**
- Disclosure: the first version of the script used TTMn at frame 0 (0.00006) as the base, giving 13.896 and a check at offset -13 (target -19); the script's own check showed the base was wrong (the g = 0 curve is 0.0004 at that x), so it was replaced by the g = 0 curve before any scene run. No scene run used the first value.

## Paragraph
The real JO -> GF wiring does what the spec wants for the primary block: a lone humming block 48 px up makes TTMn cross the press threshold 18 px before it (the calibrated middle of the one-jump window was 19), A is held 11 frames, the head hits the block, the tile goes to 196, a coin comes out, the hum stops and A is released. It is a one-point calibration, though: the nearby mushroom block was missed because the pipe face's looming adds to the same TTMn and moved the press 3 px outside the window, and the third block was hit only by the tail of the second jump. HUM_GAIN stays 14.5342 as frozen. The shuffled brains hit blocks only by pressing A in many situations; the specific signature (no A without a block or a threat) belongs to the real brain only in this run.
