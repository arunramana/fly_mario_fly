**What we learned.** This is a UI-feature demonstration run (the control round-trips through entity_profiles.json and reaches a real run -- tool/tests/test_entity_profiles_tab.py's own functional test already proves the mechanism), not a formal science finding -- no docs/RUNS.md entry per the user's own instruction. Reading too much into a single seed's max_x/stomp numbers here would overstate what one episode shows; a real claim about attractive-Goomba behaviour would need the same seeds x {real, shuffled} batch discipline as projects/legacy/runs/029_c8a_validation.md before going in docs/RUNS.md.
